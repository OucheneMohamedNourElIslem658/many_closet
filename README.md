# Many Closet

**Many Closet** is a highly customizable and modern e-commerce platform designed for selling clothing, offering advanced business management features and a seamless shopping experience. **This project is entirely open source.**

## Features

* **Customizable Business Management:** Easily manage your inventory with features for creating, updating, and deep searching products. Benefit from **deep linking** for individual products and their pricing, making it simple to share and promote specific items.
* **Multi-Choice Authentication:** We offer flexible authentication options for both **clients** and **admins**, supporting various actions like shopping, purchasing, following, and managing commands.
* **Modern Shopping Experience:** Our platform provides a user-friendly interface that prioritizes discoverability and ease of use.

## Getting Started

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

To get Many Closet up and running on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [repository-url]
    ```
    (Replace `[repository-url]` with the actual URL of your repository)

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm start
    ```
    This command runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will automatically reload as you make changes, and any lint errors will be displayed in the console.
